# Demo Script

Use this guide to demonstrate the capabilities of JobTalk.

## Preparation
1.  Ensure Backend is running: `cd server && npm run dev` (Port 3000).
2.  Ensure Frontend is running: `cd client && npm run dev` (Port 5173).
3.  Have the sample data ready (`sample_data/` folder).

## Walkthrough Steps

### 1. The "Vibe" Check
- **Action**: Open the frontend.
- **Highlight**: Point out the minimal, clean light theme and the subtle floating 3D sphere in the background. Mention it's built with Three.js.

### 2. The Upload
- **Action**: Drag and drop `sample_resume.pdf` (or copy content from `resume_content.md` and print to PDF).
- **Action**: Copy text from `job_description.txt` and paste it into the Job Description box.
- **Action**: Click "Start Analysis".
- **Highlight**: Explain that embeddings are being generated *locally* on the server (privacy/speed) while Groq analyzes the fit.

### 3. The Dashboard
- **Observation**: Wait for the results (should be fast).
- **Highlight**: Show the Match Score (circular progress), Key Strengths, and Missing Skills.
- **Note**: The analysis is structured JSON generated by Llama 3.3 70B.

### 4. The Chat (RAG)
- **Action**: Type: *"Does this candidate have experience with React?"*
- **Response**: Notice the concise, direct answer.
- **Action**: Type: *"What is their education background?"*
- **Highlight**: Explain that the bot is "reading" the resume using RAG (Retrieval Augmented Generation) to answer specific questions.

## Troubleshooting
- If analysis fails, check if the Groq API key is valid in `server/.env`.
- If chat is hallucinating, ensure the resume was parsed correctly (check server logs).
